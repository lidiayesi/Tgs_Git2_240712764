1. Apa yang terjadi jika dua anggota mengubah baris kode yang sama pada file yang sama? (merge 
conflict) 

Akan terjadi Merge Conflict. Git dan Github tidak bisa menggabungkannya secara otomatis, sehingga programmer harus menyelesaikannya secara manual untuk menentukan baris kode mana yang ingin dipertahankan dan mana yang dibuang.


2. Mengapa penggunaan branch terpisah untuk setiap anggota penting dalam kerja tim? 

Agar setiap perubahan kode terisolasi dan tidak langsung merusak kode di branch utama (main). Hal ini juga memungkinkan banyak anggota tim bekerja pada satu proyek secara bersamaan tanpa saling menimpa pekerjaan satu sama lain.


3. Apa manfaat fitur Pull Request dibandingkan langsung melakukan push ke branch main?

Pull Request berfungsi sebagai tahap review sebelum kode digabungkan ke branch utama. Dengan Pull Request, anggota tim atau ketua kelompok bisa memeriksa kode, berdiskusi, dan memastikan tidak ada error sebelum kode tersebut disetujui untuk dimerge.
